# GOD'S FLOWERS — Design System

Онлайн-академія флористики. Естетика: тепла, мінімалістична, «крафтова» — багато повітря,
тонкі лінії, великі серифні заголовки, ботанічні акценти. Мова інтерфейсу: українська.

## Colors

| Token | Hex | Використання |
|---|---|---|
| `--cream` | `#FFFCF5` | основний фон сторінки |
| `--sand` | `#F6F1EA` | вторинні секції, картки |
| `--linen` | `#EFE8DF` | розділювачі, hover-фони |
| `--taupe` | `#A2988D` | бренд-колір (з логотипа): кнопки, лінії, підписи |
| `--taupe-deep` | `#7C726A` | hover для taupe, іконки |
| `--ink` | `#333333` | основний текст |
| `--ink-soft` | `#6B655F` | вторинний текст |
| `--terracotta` | `#D64930` | акцент: розпродаж, ціни, активні стани |

Правило: кремове полотно + беж; теракота лише як точковий акцент (badge, ціна, підкреслення).
Жодних градієнтів окрім ледь помітного теплого світіння в hero.

## Typography

- **Display:** `Cormorant Garamond` (400/500/600, italic) — заголовки секцій, назви курсів, цифри.
  Курсив використовується для «людських» слів (`обирай`, `Кейси`), капс-версія — для сталих (`ФЛОРИСТИКА`).
- **Body / UI:** `Manrope` (400/500/600) — параграфи, навігація, кнопки, форми.
- Трекінг: заголовки в капсі — `0.18em`; body — нормальний.
- Шкала: 12 / 14 / 16 / 20 / 28 / 40 / 64 / 96 px (clamp на мобайлі).

## Layout

- Контейнер: `max-w-[1280px]`, горизонтальний padding 20px (mobile) → 64px (desktop).
- Вертикальний ритм секцій: 96px mobile → 160px desktop.
- Сітка порушується навмисно: заголовок секції зміщений вліво, підзаголовок — з відступом,
  картки курсів мають різну висоту зображення.
- Радіуси: 0 (лінії/бордери), 16px (картки), 999px (кнопки, пігулки).

## Components

- **Header** — sticky, кремовий з blur; ліворуч логотип, по центру навігація з двома дропдаунами
  (Offline / Online), праворуч кнопка «Звʼязатись». На <1024px — бургер + повноекранна панель.
- **Buttons** — `pill`: заповнений taupe (primary), обведений (ghost), капс, трекінг 0.14em.
- **Marquee** — рухома стрічка на теракоті з текстом акції.
- **Course card** — велика картинка 4:5, назва в два рядки (курсив + капс), опис, лінк «Детальніше →».
- **Case carousel** — горизонтальний скрол з snap, стрілки на десктопі, свайп на мобайлі.
- **Price card** — велика цифра Cormorant, тонка лінія-роздільник, підпис.
- **Form** — інпути без рамок, лише нижня лінія taupe; кнопка pill на всю ширину на мобайлі.

## Motion

Один оркестрований сценарій: `reveal` — елементи піднімаються на 24px і проявляються з
затримкою по 80ms у межах секції (IntersectionObserver, CSS-transition). Hover: лінійне
підкреслення та легке масштабування зображень (1.04, 600ms ease-out). Без паралаксу.
